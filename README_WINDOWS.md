## ✨ Возможности

### Управление устройствами
- ✅ **Включение/выключение** — свет, розетки, вентиляторы, кондиционеры
- 🔄 **Переключение** — одной командой меняет состояние на противоположное
- 🎚️ **Установка значений** — яркость, температура, положение штор
- 🎬 **Активация сцен** — запуск заранее настроенных сценариев
- ⏰ **Таймеры** — автоматическое выключение через заданное время

### Информационные команды
- 📊 **Статус устройств** — текущее состояние любого устройства
- 📋 **Списки устройств** — все устройства или по типу (свет, климат и т.д.)
- 🏠 **Комнаты** — все устройства в конкретной комнате
- 🌐 **Статус HA** — проверка доступности Home Assistant

### Дополнительные функции
- 🌍 **Мультиязычность** — русский и английский языки (переключение на лету)
- 🔒 **Безопасность** — доступ только для указанного пользователя
- 💬 **Распознавание текста** — можно писать имя устройства без команд
- 🔄 **Автообновление** — список устройств обновляется каждые 60 секунд
- 📝 **Логи** — подробное логирование всех действий

## 📦 Требования

### Системные требования
- **ОС:** Windows 10/11, Linux, macOS
- **Python:** 3.11 или выше
- **Home Assistant:** версия 2023.1 или новее
- **Интернет:** для подключения к Telegram API

### Что нужно иметь
1. **Telegram Bot Token** — токен вашего бота (получается у [@BotFather](https://t.me/BotFather))
2. **Home Assistant Long-Lived Access Token** — токен доступа к HA
3. **Ваш Telegram User ID** — числовой ID для ограничения доступа

## 🚀 Установка

### Способ 1: Автоматическая установка (Windows)

1. **Скачайте или клонируйте репозиторий:**
   ```bash
   git clone https://github.com/sergej19882906/ha-telegram-bot.git
   cd ha-telegram-bot
   ```

2. **Запустите установку:**
   ```bash
   install.bat
   ```

   Этот скрипт автоматически:
   - Создаст виртуальное окружение
   - Установит все зависимости
   - Создаст шаблон файла `.env`

3. **Заполните файл `.env`** (см. раздел [Настройка](#-настройка))

4. **Запустите бота:**
   ```bash
   start.bat
   ```

### Способ 2: Ручная установка (любая ОС)

1. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   ```

2. **Активируйте окружение:**

   **Windows:**
   ```bash
   venv\Scripts\activate
   ```

   **Linux/macOS:**
   ```bash
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install --upgrade "python-telegram-bot>=21" httpx pydantic python-dotenv
   ```

4. **Создайте файл `.env`** (см. раздел [Настройка](#-настройка))

5. **Запустите бота:**
   ```bash
   python bot.py
   ```

## ⚙️ Настройка

### 1. Получение Telegram Bot Token

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: `Мой Умный Дом`)
   - Введите username бота (должен заканчиваться на `bot`, например: `my_smart_home_bot`)
4. Скопируйте полученный токен (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Получение Home Assistant Access Token

1. Откройте веб-интерфейс Home Assistant
2. Нажмите на свой профиль (иконка человека в левом нижнем углу)
3. Прокрутите вниз до раздела **"Long-Lived Access Tokens"**
4. Нажмите **"Create Token"**
5. Введите имя (например: `Telegram Bot`)
6. Скопируйте полученный токен (длинная строка, начинающаяся с `eyJ...`)

> ⚠️ **Важно:** Сохраните токен в надёжном месте — он показывается только один раз!

### 3. Получение Telegram User ID

1. Откройте Telegram и найдите [@userinfobot](https://t.me/userinfobot) или [@getidsbot](https://t.me/getidsbot)
2. Отправьте любое сообщение боту
3. Скопируйте ваш числовой ID (например: `123456789`)

### 4. Заполнение файла `.env`

Откройте файл `.env` в текстовом редакторе и заполните:

```env
# Telegram bot token (от @BotFather)
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Home Assistant settings
HA_BASE_URL=http://192.168.1.100:8123
HA_ACCESS_TOKEN=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# Ваш Telegram ID (защита от чужих пользователей)
ALLOWED_USER_ID=123456789

# Язык по умолчанию: ru или en
DEFAULT_LANG=ru
```

**Описание параметров:**

| Параметр | Описание | Пример |
|----------|----------|--------|
| `TELEGRAM_BOT_TOKEN` | Токен вашего Telegram-бота | `123456789:ABC...` |
| `HA_BASE_URL` | Адрес вашего Home Assistant | `http://192.168.1.100:8123` |
| `HA_ACCESS_TOKEN` | Долгосрочный токен доступа к HA | `eyJhbGciOi...` |
| `ALLOWED_USER_ID` | Ваш Telegram ID (числовой) | `123456789` |
| `DEFAULT_LANG` | Язык по умолчанию (`ru` или `en`) | `ru` |

> 💡 **Совет:** Если бот и Home Assistant на одном компьютере, используйте `http://localhost:8123`

## 🤖 Команды бота

### Основные команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `/start` | Приветствие и начало работы | `/start` |
| `/help` | Список всех команд | `/help` |

### Управление устройствами

| Команда | Описание | Пример |
|---------|----------|--------|
| `/on <имя>` | Включить устройство | `/on Люстра` |

| `/toggle <имя>` | Переключить вкл/выкл | `/toggle Торшер` |

| Команда | Описание | Пример |

| Команда | Описание | Пример |

## 🪟 Запуск на Windows

В проекте предусмотрены готовые `.bat`-файлы для удобного запуска на Windows.

### `install.bat` — Первоначальная установка
Запускается один раз. Создаёт виртуальное окружение, устанавливает зависимости и создаёт шаблон `.env`.

### `start.bat` — Запуск бота
Основной файл для запуска. Проверяет наличие `venv` и `.env`, активирует окружение и запускает `bot.py`.

### `start_log.bat` — Запуск с логированием
Аналогичен `start.bat`, но дополнительно сохраняет весь вывод в файл `logs/bot.log`.

### `stop.bat` — Остановка
Закрывает все окна с запущенным ботом.

### Как пользоваться:
1. **Первый раз:** двойной клик на `install.bat` → заполните `.env` → двойной клик на `start.bat`
2. **Дальше:** просто двойной клик на `start.bat`

## 🔄 Автозапуск при старте системы

Чтобы бот запускался автоматически при включении компьютера и работал в фоне:

### Способ 1: Через папку «Автозагрузка»

1. Нажмите `Win + R`, введите `shell:startup` и нажмите Enter
2. Скопируйте туда ярлык файла `start.bat` (или сам `start.bat`)

### Способ 2: Скрытый запуск (без окна)

Создайте файл `run_hidden.vbs` рядом с `start.bat`:

```vbs
Set WshShell = CreateObject("WScript.Shell")
WshShell.Run chr(34) & "E:\PR\ha-telegram-bot\start.bat" & chr(34), 0
Set WshShell = Nothing
```

> ⚠️ Замените путь `E:\PR\ha-telegram-bot\start.bat` на ваш реальный путь.

Положите этот `.vbs` файл в папку автозагрузки (`shell:startup`) — бот будет запускаться в фоне без окна.

### Способ 3: Через Планировщик заданий Windows

1. Откройте **Планировщик заданий** (`taskschd.msc`)
2. Создайте простую задачу:
   - **Имя:** HA Telegram Bot
   - **Триггер:** При входе в систему
   - **Действие:** Запуск программы → укажите путь к `start.bat`
   - **Начало в:** папка `E:\PR\ha-telegram-bot\`
3. В свойствах задачи отметьте «Выполнять с наивысшими правами» (опционально)

## 🔧 Решение проблем

### Ошибка: `TELEGRAM_BOT_TOKEN and HA_ACCESS_TOKEN are required`

**Причина:** Не заполнен файл `.env` или он находится не в той папке.

**Решение:**
1. Убедитесь, что файл `.env` находится в папке с `bot.py`
2. Проверьте, что все параметры заполнены (без пробелов вокруг `=`)
3. Перезапустите бота

---

### Ошибка: `Invalid HA access token`

**Причина:** Неверный токен Home Assistant или HA недоступен.

**Решение:**
1. Проверьте правильность `HA_ACCESS_TOKEN` в `.env`
2. Убедитесь, что Home Assistant запущен и доступен по адресу из `HA_BASE_URL`
3. Попробуйте открыть `HA_BASE_URL` в браузере
4. Создайте новый токен в HA (старый мог быть отозван)

---

### Ошибка: `Cannot parse entities: unsupported start tag`

**Причина:** В имени устройства есть символы `<` или `>`, которые Telegram пытается интерпретировать как HTML.

**Решение:** Обновите бота до последней версии — эта ошибка уже исправлена (все пользовательские данные экранируются).

---

### Бот не отвечает на команды

**Причина:** Ваш Telegram ID не совпадает с `ALLOWED_USER_ID`.

**Решение:**
1. Узнайте свой ID через [@userinfobot](https://t.me/userinfobot)
2. Обновите `ALLOWED_USER_ID` в файле `.env`
3. Перезапустите бота

---

### Ошибка: `RuntimeError: Cannot send a request, as the client has been closed`

**Причина:** Конфликт версий библиотек или неправильная работа с event loop.

**Решение:** Обновите зависимости:
```bash
pip install --upgrade "python-telegram-bot>=21" httpx pydantic python-dotenv
```

---

### Ошибка: `Only timezones from the pytz library are supported`

**Причина:** Несовместимость версий `apscheduler` и `python-telegram-bot`.

**Решение:** В текущей версии бота `JobQueue` отключён, эта ошибка не должна возникать. Если всё же появляется, установите совместимую версию:
```bash
pip install "apscheduler>=3.10,<3.11"
```

---

### Устройства не находятся по имени

**Причина:** Имя устройства в HA не совпадает с тем, что вы пишете боту.

**Решение:**
1. Проверьте точное имя устройства в HA (команда `/entities`)
2. Используйте команду `/state` без параметров — увидите все устройства
3. Бот создаёт алиасы из `friendly_name`, но они могут не совпадать с тем, что вы ожидаете

---

### Бот запускается, но сразу закрывается

**Причина:** Ошибка в коде или конфигурации, окно закрывается до того, как вы успеваете увидеть ошибку.

**Решение:**
1. Запустите бота через `start.bat` — он не закроет окно при ошибке
2. Или откройте командную строку вручную, перейдите в папку проекта и запустите:
   ```bash
   venv\Scripts\activate
   python bot.py
   ```

## 🔄 Обновление

### Автоматическое обновление (Windows)

1. Остановите бота (Ctrl+C в окне)

## 👨‍💻 Разработка

### Добавление новых команд

1. Откройте `bot.py`
2. Найдите класс `HATelegramBot`
3. Добавьте новый метод:
   ```python
   async def cmd_mycommand(self, update: Update, context: ContextTypes.DEFAULT_TYPE):
       if not self._check_auth(update):
           return
       uid = self._uid(update)
       # Ваш код здесь
       await self._reply_text(update, t(uid, "my_message"))
   ```
4. Добавьте тексты в словарь `MESSAGES` (для `ru` и `en`)
5. Зарегистрируйте команду в функции `main()`:
   ```python
   app.add_handler(CommandHandler("mycommand", bot.cmd_mycommand))
   ```

### Добавление нового языка

1. Откройте `bot.py`
2. Найдите словарь `MESSAGES`
3. Добавьте новый ключ (например, `"de"` для немецкого)
4. Скопируйте все ключи из `"ru"` или `"en"` и переведите значения
5. Готово — пользователи смогут выбрать новый язык через `/lang`

### Логирование

Все логи пишутся в консоль и в файл `logs/bot.log` (если запущен через `start_log.bat`).

Уровень логирования можно изменить в `bot.py`:
```python
logging.basicConfig(
    format="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
    level=logging.INFO,  # Измените на DEBUG для подробных логов
)
```

### Архитектура проекта

- **`Config`** — загрузка настроек из `.env`
- **`HAClient`** — асинхронный клиент для общения с Home Assistant API
- **`EntityRegistry`** — хранение списка устройств и их алиасов
- **`HATelegramBot`** — основной класс с обработчиками команд
- **`MESSAGES`** — словарь локализации (ru/en)
- **`main()`** — точка входа, настройка приложения Telegram

- Логи пишутся в консоль — при длительной работе рекомендуется использовать `start_log.bat`

### Совместимость
- Протестировано с Home Assistant 2023.1+
- Поддерживаются все основные типы устройств: light, switch, fan, climate, cover, scene
- Для кастомных компонентов может потребоваться доработка кода
